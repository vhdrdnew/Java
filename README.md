# Java
Task Manager LR1

Консольний застосунок для введення характеристик задачі
(назва, пріоритет, оцінка часу, статус, категорія)
з розрахунком орієнтовної вартості виконання.

Опис сутності

Основна сутність - Task. Вона описує елемент, з якими працює трекер завдань, і має такі характеристики:
title (String) - назва задачі
priority (int) - пріоритет: 1-високий, 2-середній, 3-низький
estimatedHours (double) - орієнтовна оцінка часу виконання, у годинах
isDone (boolean) - статус виконання: true-виконано, false-в процесі
category (String) - категорія задачі (наприклад, "Навчання", "Робота", "Особисте")
Обчислювана характеристика

На основі оцінки часу (estimatedHours) і фіксованої погодинної ставки програма розраховує орієнтовну вартість виконання задачі, щоб можна було приблизно оцінити "ціну" задачі в грошовому еквіваленті.

Запуск

javac TaskManager.java

java TaskManager
